# BAYAN Knowledge Core

قاعدة المعرفة الأصلية لمنصة BAYAN Arabic B.

## المبادئ

- المحتوى التعليمي داخل هذه القاعدة أصلي ومن إنتاج BAYAN.
- لا تحتوي القاعدة على نصوص منسوخة من كتب تجارية.
- الأطر العالمية تستخدم للتوجيه والتصنيف فقط.
- أوصاف المستويات مكتوبة بصياغة أصلية وليست نقلًا حرفيًا.
- كل عنصر معرفي يحمل بيانات المصدر والترخيص والمراجعة.

## المستويات

- A0: تمهيدي
- A1: مبتدئ
- A2: أساسي
- B1: متوسط
- B2: فوق المتوسط

## أقسام المعرفة

- frameworks: إطار المستويات والتقدم.
- vocabulary: المفردات والتراكيب.
- grammar: القواعد الوظيفية.
- skills: أهداف المهارات.
- dialogues: الحوارات والمواقف الحياتية.
- assessments: بنوك الأسئلة والتقييم.
- culture: المعرفة الثقافية.
- generated: الفهرس الموحد الناتج آليًا.
- reports: تقارير الجودة والتحقق.
